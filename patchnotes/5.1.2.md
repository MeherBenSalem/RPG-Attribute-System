# RPG Attribute System 5.1.2

## Fixes

### `use_vanilla_xp` gave no VP at all on Fabric

With `use_vanilla_xp` set to `true` in `config/ras/settings.json`, mob kills stop paying RAS's own VP and pay the XP
the mob drops instead. Forge and NeoForge did this, but the Fabric builds never had the vanilla-XP side, so on
Fabric (every version) players with the setting on earned no VP at all. Fabric now pays a kill the XP the mob
drops, the same as the other loaders, and shows `+N VP` in the action bar when `show_vp_inaction_bar` is on.

Only XP from kills counts, on every loader. XP that other mods hand out for mining, building or crafting is not
converted.

## Changes

### Turn an attribute off completely: `"enabled": false`

Each attribute file in `config/ras/attributes/` has a new `enabled` setting (default `true`; existing files get it on
the next start). With `"enabled": false` the attribute is gone from the game: it isn't sent to players, isn't shown in
any menu, can't take points and its commands never run. Before, the only option was `"lock": true`, which still shows
the attribute greyed out as locked, and deleted attribute files were recreated on the next start.

Points a player already spent in an attribute keep their effect after it's turned off, so turn attributes off before
players start, or reset their stats.

No save changes.
