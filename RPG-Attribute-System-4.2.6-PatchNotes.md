# RPG Attribute System — 4.2.6 Patch Notes

**Supported platforms:** Minecraft 1.20.1 (Fabric, Forge) · Minecraft 1.21.1 (Fabric, NeoForge) · Minecraft 26.1.2 (Fabric, NeoForge) · Minecraft 26.2 (Fabric, NeoForge)

## Bug fixes

- **HUD respects Hide GUI (F1)** — the RAS level/VP overlay now hides with the vanilla HUD when Hide GUI is on.

## Upgrade

Replace the loader jar for your Minecraft version with **4.2.6**. Server and clients should run the same RAS version.
